# Jogo da Memória

Jogo da memória entre jogadores conectados à um mesmo middleware.

## Tarefas de Desenvolvimento

### Task 1: Interface RMI + Servidor Esqueleto
- Definir a interface RMI com os métodos remotos necessários
- Implementar o servidor esqueleto (skeleton) para gerenciar conexões
- Configurar o registro RMI para disponibilizar os serviços

### Task 2: Lógica do Jogo no Servidor
- Implementar a lógica do jogo da memória no servidor
- Gerenciar o estado do tabuleiro e as cartas
- Implementar validação de jogadas e pontuação
- Controlar turnos entre jogadores

### Task 3: Interface Gráfica no Cliente
- Desenvolver a interface gráfica do jogo
- Criar o tabuleiro visual com as cartas
- Implementar animações e feedback visual
- Exibir informações de pontuação e turno atual

### Task 4: Lógica de Conexão e Turnos no Cliente
- Implementar cliente RMI para conexão com o servidor
- Gerenciar comunicação cliente-servidor
- Sincronizar turnos entre jogadores
- Tratar eventos de rede e desconexões
